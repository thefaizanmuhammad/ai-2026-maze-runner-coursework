# AI 2026 — Maze Runner Coursework

## Project Overview

This project is based on the **Escape the Maze** AI mini project.

We will implement classical AI search algorithms and the key-hunt problem using the starter code provided by the instructor.

Main files we will work on:

- `search.py`
- `heuristics.py`
- `griever_hole.py`

The remaining starter files should only be changed if absolutely necessary.

- `faizan` — Faizan's working branch

### Rules

1. Do not develop directly on `main`.
2. Each person works on their own branch.
3. Commit after completing or meaningfully updating a task.
4. Test code before merging.
5. Merge completed work into `main` through a pull request.
6. Keep your branch updated with the latest `main` when needed.
